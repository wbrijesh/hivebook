= Standards
:status: living
:last-reviewed: 2026-06-06

Conventions everyone follows so independent decisions converge. Architecture
decides _what_ we build; standards keep us from building it five slightly
different ways.

Entropy in a codebase rarely comes from architecture. It comes from many people
making slightly different local choices — five logging styles, four error
shapes, three response formats, ad-hoc directory layouts, inconsistent tests.
Standards remove those choices so they stop being decisions.

== The rule

. *Follow the standard.* If none exists for what you're doing, the surrounding
code is the standard — match it.
. *Disagree in writing, not in passing.* To change a standard, change its page
in a PR; don't fork it locally.
. *Standards state what is* (or what we've committed to), in the terse voice of
xref:ROOT:style-guide.adoc[the style guide].
